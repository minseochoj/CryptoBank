# CryptoBank

CryptoBank facilitates secure, decentralized transactions via real-time verification and two-factor authentication on a private, wallet-based platform.

CryptoBank is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/CryptoBank.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
